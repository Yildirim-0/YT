YT

A personal automation tool for a single YouTube channel.

YT runs on the channel owner's own computer. It uses the YouTube Data API to:

  • find newly uploaded private videos on the owner's channel,
  • add a standard description and schedule them for publishing,
  • post a comment on the video after it is published.

It is not a public service. It only acts on the channel of the person who signed in, and only on their own computer.
